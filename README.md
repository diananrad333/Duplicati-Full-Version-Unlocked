## Main Features
<a id="main-features"></a>

### Core Functionality
- **Incremental Backups** — Duplicati allows users to create incremental backups that only save changes made since the last backup, optimizing storage space and backup time.
- **User-Friendly Wizard** — The application features a guided assistant that simplifies the process of setting up backups, making it accessible even for beginners.
- **Multiple Storage Options** — Users can back up data to various locations including local hard drives, external drives, FTP servers, and popular cloud services like Amazon S3 and Google Drive.
- **Scheduled Backups** — Duplicati enables users to schedule regular backups, ensuring up-to-date copies of their data are created without needing manual intervention.
- **Encryption and Compression** — The software offers strong encryption for backups, protecting sensitive data, while also compressing files to save storage space.

### Advanced Capabilities
- **Cloud Integration** — Duplicati supports integration with multiple cloud storage solutions, giving users flexibility in choosing their backup destination.
- **Web Interface** — The application can be managed through a web interface, allowing users to monitor and manage their backups remotely.
- **Email Notifications** — Users can set up email notifications to receive alerts on backup statuses, ensuring they are informed about the success or failure of backup processes.
- **Command Line Interface** — For advanced users, Duplicati offers a command line interface that allows for scripting and automation of backup tasks.
